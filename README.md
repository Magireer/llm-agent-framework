# LLM Agent Framework

![License](https://img.shields.io/badge/license-MIT-blue) ![Python](https://img.shields.io/badge/python-3.9%2B-green)

Build complex multi-agent workflows with ease. This framework provides the building blocks for agent communication, tool use, and state management.

## Features
- Asynchronous agent execution
- Built-in tool registry
- State persistence and history management

## Usage
```python
from agent_framework import Agent, Orchestrator
```
